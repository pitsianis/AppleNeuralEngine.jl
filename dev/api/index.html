API reference

Compiling and running

AppleNeuralEngine.compile — Function
compile(mil; input_shapes, output_shapes, weight_blob=nothing,
        input_types=Float32, output_types=Float32)

Compile one MIL program with the private ANE runtime and load it onto the Neural Engine. Inputs and outputs are contiguous buffers of Float32 or Float16 (one type for all, or one per tensor, matching the MIL program); each shape gives the size of the Julia array that is copied in or out, and its memory layout must match the tensor in the MIL program.

weight_blob is the program's weight file, @model_path/weights/weight.bin, usually made with build_weight_blob or, for several tensors, pack_weights.

The runtime binds MIL inputs and outputs to buffer indices in sorted name order, not declaration order.

source
compile(g::MIL.Graph) -> ANEProgram

Compile a program built with the MIL graph builder. Its inputs and outputs are Julia arrays with the MIL dimensions reversed and singleton dimensions dropped: a MIL [1, C, 1, S] tensor is a Julia (S, C) matrix.

source
compile(f, inputs...) -> ANEProgram

Trace f (see trace) and compile it for the Neural Engine. The program is callable: program(x...) returns the output (or a tuple of outputs).

W = randn(Float32, 512, 2048)
program = compile(x -> max.(x * W, 0), randn(Float16, 256, 512))
y = program(x)

AppleNeuralEngine.trace — Function
trace(f, inputs...) -> MIL.Graph

Record f applied to placeholders for inputs (example arrays, or sizes (n,) / (m, n), which mean Float16 inputs) as a MIL graph. f returns an array or a tuple of arrays.

AppleNeuralEngine.ANEProgram — Type
ANEProgram

A MIL program compiled and loaded onto the Neural Engine, with its input and output buffers. Create one with compile; run it with evaluate! or by calling it, program(inputs...). A program holds Neural Engine resources until close! is called or it is garbage collected.

source
AppleNeuralEngine.evaluate! — Function
evaluate!(program, inputs...) -> Vector{Array}

Copy inputs into the program's input buffers, run it on the Neural Engine and return freshly allocated output arrays.

source
AppleNeuralEngine.close! — Function
close!(program::ANEProgram)

Unload program from the Neural Engine and free its buffers. Safe to call more than once; afterwards the program cannot be evaluated.

Weights

AppleNeuralEngine.WeightFile — Type
WeightFile()

An ANE weight file that tensors are appended to one at a time with push!(file, array), which returns the offset a MIL BLOBFILE uses to refer to the tensor. bytes(file) returns the file contents for compile.

Arrays are stored in MIL (row-major) order: element A[i, j, k] is MIL element [i, j, k], so a conv weight [Cout, Cin, kh, kw] is the Julia array W[cout, cin, kh, kw]. The element type is kept; supported types are Float16, Float32, Int16, Int32, Int8, UInt16, UInt8.

source
AppleNeuralEngine.pack_weights — Function
pack_weights(tensors...; transposed=false) -> (blob, offsets)

Encode several Float32 matrices as fp16 tensors in one ANE weight file. Pass blob to compile as weight_blob and refer to tensor i in the MIL program as

BLOBFILE(path = string("@model_path/weights/weight.bin"), offset = uint64(offsets[i]))

Each tensor is stored in row-major order, so a conv weight [Cout, Cin, 1, 1] is the matrix W[cout, cin]; with transposed=true every tensor is stored transposed. A vector (e.g. a per-channel scale) can be passed as a 1×n matrix. See WeightFile for tensors of other ranks and element types.

source
AppleNeuralEngine.build_weight_blob — Function
build_weight_blob(weights::AbstractMatrix{Float32}; transposed=false)

Encode one Float32 matrix as an fp16 ANE weight file, referred to in MIL as BLOBFILE(path = string("@model_path/weights/weight.bin"), offset = uint64(64)). See pack_weights for several tensors and for the storage order.

source
AppleNeuralEngine.bytes — Function
bytes(file::WeightFile) -> Vector{UInt8}

The contents of the weight file, to pass to compile as weight_blob.

MIL graph builder

AppleNeuralEngine.MIL — Module
MIL

A builder for MIL programs, the input language of the ANE compiler. Ops are Julia functions on Vars that infer output types and shapes, so the generated program is always well-typed:

using AppleNeuralEngine, AppleNeuralEngine.MIL
g = MIL.Graph()
x = MIL.input(g, :x, Float16, (1, 64, 1, 32))
W = MIL.constant(g, randn(Float32, 64, 64, 1, 1))
MIL.output!(g, MIL.relu(MIL.conv(x, W)))
program = compile(g)

Function names and arguments follow the MIL op set as documented by coremltools; several shadow Base names (exp, reshape, ...), so call them qualified (MIL.exp) rather than using the module.

source
AppleNeuralEngine.MIL.Graph — Type
Graph(; opset="ios18")

A MIL program being built. Create inputs with input, apply ops to the resulting Vars, mark results with output!, then pass the graph to compile or print it with source.

source
AppleNeuralEngine.MIL.Var — Type
Var

A value in a Graph: a tensor with a MIL element type and a MIL shape (row-major, outermost dimension first; () for a scalar). Vars are produced by input, constant and the op functions.

source
AppleNeuralEngine.MIL.input — Function
input(g, name, T, shape; julia_shape=nothing) -> Var

Declare a program input of element type T (Float32 or Float16) and MIL shape shape. Inputs are passed to evaluate! in declaration order, as Julia arrays of size julia_shape; by default that is shape reversed with singleton dimensions dropped, the array with the same memory layout.

source
AppleNeuralEngine.MIL.output! — Function
output!(g, v, name=v.name; julia_shape=nothing)

Mark v as a program output. Outputs are returned by evaluate! in the order they are marked, as Julia arrays of size julia_shape (see input). They must be Float32 or Float16.

source
AppleNeuralEngine.MIL.constant — Function
constant(g, value; eltype=Float16) -> Var

A constant tensor. Arrays are stored in the program's weight file, converted to eltype and indexed the MIL way (A[i, j] is MIL element [i, j]); see WeightFile. Numbers become scalar constants.

source
AppleNeuralEngine.MIL.constant_int8 — Function
constant_int8(g, W; axis=0) -> Var

A constant stored as int8 with one fp16 scale per slice along axis (symmetric quantization), dequantized by the ANE when the program is loaded (constexpr_affine_dequantize). Halves the weight memory of fp16 constants.

source
AppleNeuralEngine.MIL.op! — Function
op!(g, op, args, outputs; name=op) -> Var or Tuple{Var...}

Append the MIL operation op to g. args are name => value pairs (values are Vars or literals; nothing omits an optional argument) and outputs are (eltype, shape) pairs, one per result. This is the escape hatch for ops that have no wrapper; the wrappers in this module call it after inferring shapes.

source
AppleNeuralEngine.MIL.source — Function
source(g) -> String

The MIL text of g, as passed to the ANE compiler.

source
AppleNeuralEngine.MIL.weight_blob — Function
weight_blob(g) -> Union{Vector{UInt8},Nothing}

The weight file holding g's constants, or nothing if it has none.

Tracing

AppleNeuralEngine.Traced — Type
Traced

A placeholder for a Julia vector or matrix while a function is traced by compile(f, inputs...). Supports broadcasting with arbitrary scalar functions built from arithmetic, exp, log, sqrt, tanh, abs, max, min, comparisons and ifelse; matrix products and adjoint; and sum, maximum, minimum with dims.
