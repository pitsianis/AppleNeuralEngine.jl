AppleNeuralEngine.jl

Run Julia code on the Apple Neural Engine (ANE), the fp16 neural-network accelerator in every Apple Silicon Mac.

using AppleNeuralEngine

W = randn(Float32, 512, 2048) ./ 23
layer(x) = max.(x * W, 0)                 # ordinary Julia

x = randn(Float16, 256, 512)
program = compile(layer, x)               # traced, compiled for the ANE
y = program(x)                            # runs on the Neural Engine

The package drives Apple's private AppleNeuralEngine.framework directly from Julia through ObjectiveC.jl. There is no native code to build and no Core ML model to export. It offers three levels of control:

levelyou writesee
tracingplain Julia on matrices: broadcasting, *, sum, ...Tracing Julia functions
graph builderMIL operations with inferred types, e.g. MIL.conv(x, W)The MIL graph builder
raw runtimeMIL program text and buffersRaw MIL and the runtime

Installation

using Pkg
Pkg.add("AppleNeuralEngine")

Requirements: an Apple Silicon Mac and Julia 1.10 or later. Nothing else needs to be installed.

Private API

The ANE has no public programming interface; Apple exposes it only through Core ML. This package uses undocumented framework classes that may change with any macOS release. initialize!() checks that the classes it needs exist. Do not rely on it for production systems.

What the Neural Engine is good at

  • fp16 matrix-matrix work. On an M2 Max a transformer feed-forward block (512 → 1536 → 512, 256 tokens) runs in about 0.26 ms, 10× faster than Float32 with Accelerate on the CPU. A 2048³ matrix product reaches about 10 TFLOP/s, 4× Accelerate (benchmark/run.jl).
  • Fixed graphs with constant weights. Weights are compiled into the program.
  • Activations, normalizations, reductions, convolutions, attention. See Op support.

It is less suited to small, latency-bound work. Every call costs about 0.1–0.2 ms on top of the compute, and the hardware computes only in fp16 (see Hardware notes).
